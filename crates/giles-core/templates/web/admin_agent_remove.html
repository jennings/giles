Removing the agent {{ id }} does this:

  • Moves its directory agents/{{ id }}/ (agent.toml, SOUL.md, its memory, its jobs' prompt files, its skills) to {{ trash }}/{{ id }}-<date and time, UTC>/ in Giles' data directory. Nothing is deleted. To bring the agent back, move that directory back to agents/{{ id }}/ and restart Giles.
  • Takes the agent out of the running Giles at once: it no longer shows in the lists or the chat chooser, a chat can't be started with it, and its existing chats can't be continued.
  • {% if config_jobs == 0 %}It has no jobs in agent.toml.{% else %}Stops the {{ config_jobs }} job{% if config_jobs != 1 %}s{% endif %} in its agent.toml; they stay in the moved file.{% endif %}
  • {% if runtime_jobs == 0 %}It has no jobs it scheduled itself.{% else %}Deletes the {{ runtime_jobs }} job{% if runtime_jobs != 1 %}s{% endif %} the agent scheduled itself (with the schedule tool). That can't be undone.{% endif %}
  • Keeps its chats, messages, and usage in the database, out of sight. If you later create an agent with the same id, those chats belong to it again.

The trash directory is not part of giles backup, and Giles never reads or empties it.
